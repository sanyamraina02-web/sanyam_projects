# New Dork

A cosy, top-down pixel-art town district where every pixel is drawn by code: no image files, no game engine, one HTML page.

- 19 procedurally designed houses (walls, roofs, chimneys, windows, mailboxes)
- Pigeon Green park: fountain, pond, flower beds, benches, Pickle the cat
- A customisable player character, five villagers with routines, day/night with lamp and window lighting
- **Remodel** regenerates every house from a new seed

## Run locally
Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy
It is a static site. On Vercel: `vercel deploy --prod` from this folder (no build step).

## Controls
WASD / arrow keys to walk · E or Space to interact · click or tap to walk to a spot.
